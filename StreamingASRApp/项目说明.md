# StreamingASRApp 项目说明

## 📝 项目概述

这是一个基于 sherpa-onnx 的**独立Android实时语音识别应用**，从sherpa-onnx官方仓库中提取并整合了必要的组件。

## 🎯 项目需求实现

按照您的要求，本项目完整实现了以下功能：

### ✅ 配置要求
- **targetSdk = 34** ✓ (Android 14)
- **sourceCompatibility = JavaVersion.VERSION_17** ✓ (Java 17)

### ✅ 功能要求
- **实时流式语音识别** ✓ (边说边识别)
- **PCM格式音频接收** ✓ (16-bit PCM, 16kHz)
- **语音缓存** ✓ (自动保存PCM格式录音)
- **模型位置** ✓ (`/data/data/com.example.streamingasr/files/models/`)

## 📦 项目组成

### 1. 核心组件

#### MainActivity.kt
- 主界面Activity
- 实现录音控制和实时识别显示
- 管理识别生命周期

#### AudioRecorder.kt
- **PCM格式录音器**
- 支持实时读取音频数据
- **自动缓存PCM数据**
- 支持导出WAV格式
- 功能：
  - `startRecording(savePcm: Boolean)` - 开始录音
  - `readAudioData()` - 读取PCM数据（FloatArray）
  - `stopRecording()` - 停止录音
  - `exportToWav()` - 导出WAV文件
  - `getCurrentPcmFile()` - 获取PCM缓存文件

#### ModelManager.kt
- 模型文件管理
- 从内部存储加载模型（`/data/data/com.example.streamingasr/files/models/`）
- 支持三种模型类型：
  - ZIPFORMER_TRANSDUCER（推荐）
  - PARAFORMER
  - ZIPFORMER_CTC

### 2. Sherpa-ONNX Kotlin API

从官方仓库复制的API文件：
- `OnlineRecognizer.kt` - 在线识别器
- `OnlineStream.kt` - 音频流处理
- `FeatureConfig.kt` - 特征配置
- `HomophoneReplacerConfig.kt` - 同音词替换配置
- `WaveReader.kt` - WAV文件读取

### 3. UI组件

- `activity_main.xml` - 主界面布局
- `strings.xml` - 字符串资源

- `themes.xml` - 主题配置

### 4. 配置文件

- `settings.gradle.kts` - Gradle设置
- `gradle.properties` - Gradle属性
- `AndroidManifest.xml` - Android清单文件

### 5. 辅助文件

## 🔧 技术细节

### 音频处理
- **采样率**: 16000 Hz
- **通道**: 单声道 (MONO)
- **格式**: PCM 16-bit
- **缓冲区**: 100ms (1600 samples)

### PCM缓存机制
```kotlin
// 音频数据流程
麦克风 → AudioRecord → ShortArray → FloatArray → OnlineStream
                          ↓
                     PCM缓存文件
                     (audio_{timestamp}.pcm)
```

### 模型加载
```kotlin
// 模型路径：/data/data/com.example.streamingasr/files/models/
- encoder-epoch-99-avg-1.onnx
- decoder-epoch-99-avg-1.onnx
- joiner-epoch-99-avg-1.onnx
- tokens.txt
```

### 实时识别流程
```
1. 创建识别流 (createStream)
2. 接收音频 (acceptWaveform)
3. 解码处理 (decode)
4. 获取结果 (getResult)
5. 检查端点 (isEndpoint)
6. 重置或释放 (reset/release)
```

## 🚀 使用流程

### 1. 准备JNI库
```bash
./download-libs.sh
```

### 2. 下载模型
```bash
wget https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-streaming-zipformer-bilingual-zh-en-2023-02-20.tar.bz2
tar xvf sherpa-onnx-streaming-zipformer-bilingual-zh-en-2023-02-20.tar.bz2
```

### 3. 编译安装
```bash
./gradlew installDebug
```

### 4. 推送模型
```bash
# 使用run-as（无需root）
adb push *.onnx /sdcard/
adb push tokens.txt /sdcard/
adb shell run-as com.example.streamingasr
mkdir -p files/models/
cp /sdcard/*.onnx files/models/
cp /sdcard/tokens.txt files/models/
```

### 5. 运行应用
1. 打开应用
2. 授予录音权限
3. 点击"开始识别"
4. 说话并查看实时识别结果

## 📝 开发笔记

### 为什么使用内部存储？
- 更安全（其他应用无法访问）
- 无需存储权限（Android 10+）
- 应用卸载时自动清理

### 为什么缓存PCM格式？
- PCM是原始音频格式，无损
- 便于后续处理和分析
- 可以灵活转换为其他格式（WAV, MP3等）

### 为什么选择Java 17？
- Android Studio最新版本推荐
- 更好的语言特性支持
- 符合现代Android开发标准
