# Sherpa-ONNX AAR 热词功能使用说明

---

## 概述

Sherpa-ONNX AAR 支持**热词（Hotwords）**功能，可以提高特定词语的识别准确率。热词在以下场景特别有用：

- 人名、地名等专有名词
- 行业术语、技术词汇
- 产品名称、品牌名
- 需要高准确率识别的关键词

---

## 热词的两种使用方式

### 方式1: 全局热词文件（推荐）

在创建识别器时指定热词文件，所有识别流共享这些热词。

#### 步骤1: 准备热词文件

在 ASR 模型目录创建 `hotwords.txt` 文件：

**路径**: `/data/data/你的包名/files/models/asr/hotwords.txt`

**格式**: 每行一个热词
```
张三
李四
北京市朝阳区
神经网络
深度学习
Transformer
```

#### 步骤2: 创建识别器时指定热词

```kotlin
val recognizer = modelManager.createOnlineRecognizer(
    modelType = ModelManager.ModelType.ZIPFORMER_TRANSDUCER,
    numThreads = 4,
    hotwordsFile = "hotwords.txt",    // 热词文件名
    hotwordsScore = 2.0F               // 热词权重（默认 1.5）
)
```

**参数说明**:

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `hotwordsFile` | String? | null | 热词文件名（位于 ASR 模型目录） |
| `hotwordsScore` | Float | 1.5 | 热词权重分数（值越大热词效果越强） |

**hotwordsScore 调优**:
- `1.0` - 无明显效果
- `1.5` - 默认值，轻微提升
- `2.0` - 中等提升（推荐）
- `3.0` - 强烈提升（可能导致误识别）
- `5.0+` - 极强提升（小心过拟合）

#### 使用 ModelFiles 指定热词

```kotlin
val modelFiles = ModelFiles(
    encoder = "encoder-epoch-99-avg-1.onnx",
    decoder = "decoder-epoch-99-avg-1.onnx",
    joiner = "joiner-epoch-99-avg-1.onnx",
    tokens = "tokens.txt",
    hotwordsFile = "my-hotwords.txt"  // 自定义热词文件名
)

val recognizer = modelManager.createOnlineRecognizer(
    modelFiles = modelFiles,
    hotwordsScore = 2.0F
)
```

---

### 方式2: 动态热词（每个流不同）

为每个识别流设置不同的热词，更灵活但需要手动管理。

#### 使用方法

```kotlin
// 创建识别器（不指定全局热词文件）
val recognizer = modelManager.createOnlineRecognizer()

// 为不同的流指定不同的热词
val stream1 = recognizer?.createStream(hotwords = "张三/3.0 李四/3.0")
val stream2 = recognizer?.createStream(hotwords = "北京/2.0 上海/2.0")
```

#### 动态热词格式

```
词1/权重1 词2/权重2 词3/权重3
```

**示例**:
```kotlin
val hotwords = "张三/3.0 李四/3.0 王五/3.0 深度学习/2.5 神经网络/2.5"
val stream = recognizer?.createStream(hotwords = hotwords)
```

**注意**:
- 词之间用空格分隔
- 每个词后面跟 `/权重`
- 权重范围：1.0 - 5.0

## 完整使用示例

### 示例1: 使用全局热词文件

```kotlin
class MainActivity : AppCompatActivity() {

    private lateinit var modelManager: ModelManager
    private var recognizer: OnlineRecognizer? = null

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        modelManager = ModelManager(this)

        // 准备热词文件
        prepareHotwordsFile()

        // 初始化识别器
        initializeRecognizer()
    }

    private fun prepareHotwordsFile() {
        // 创建热词文件
        val hotwordsFile = File(modelManager.getModelDir(), "asr/hotwords.txt")

        if (!hotwordsFile.exists()) {
            hotwordsFile.writeText("""
                张三
                李四
                王五
                深度学习
                神经网络
                Transformer
                BERT
                GPT
            """.trimIndent())

            Log.i(TAG, "热词文件已创建: ${hotwordsFile.absolutePath}")
        }
    }

    private fun initializeRecognizer() {
        lifecycleScope.launch(Dispatchers.IO) {
            recognizer = modelManager.createOnlineRecognizer(
                modelType = ModelManager.ModelType.ZIPFORMER_TRANSDUCER,
                numThreads = 4,
                hotwordsFile = "hotwords.txt",  // 启用热词
                hotwordsScore = 2.0F             // 热词权重
            )

            withContext(Dispatchers.Main) {
                if (recognizer != null) {
                    Log.i(TAG, "✓ 识别器已加载（热词已启用）")
                    startRecognition()
                }
            }
        }
    }

    private fun startRecognition() {
        val stream = recognizer?.createStream()

        // 正常识别流程
        // ...
    }
}
```

        val techStream = createStreamForSpeaker("技术总监")
        val salesStream = createStreamForSpeaker("销售经理")

        // ...
    }
}

### 示例3: 实时更新热词

```kotlin
class DynamicHotwordsDemo : AppCompatActivity() {

    private var recognizer: OnlineRecognizer? = null
    private var currentStream: OnlineStream? = null

    // 根据上下文动态更新热词
    private fun switchTopic(topic: String) {
        // 释放旧流
        currentStream?.release()

        // 根据话题创建新流并设置热词
        val hotwords = when (topic) {
            "医疗" -> "诊断/3.0 治疗/3.0 药物/3.0 症状/3.0"
            "法律" -> "诉讼/3.0 判决/3.0 律师/3.0 法规/3.0"
            "金融" -> "投资/3.0 股票/3.0 基金/3.0 收益/3.0"
            else -> ""
        }

        currentStream = recognizer?.createStream(hotwords = hotwords)

        Log.i(TAG, "切换话题到: $topic, 热词: $hotwords")
    }
}
```

## 热词 vs HomophoneReplacer 区别

| 功能 | 热词 (Hotwords) | 同音字纠正 (HomophoneReplacer) |
|------|----------------|-------------------------------|
| **作用** | 提高特定词语的识别准确率 | 纠正同音字错误 |
| **原理** | 在解码时提升特定词语的分数 | 后处理替换错误文本 |
| **配置** | hotwords.txt + hotwordsScore | lexicon.txt + replace.fst |
| **使用场景** | 专有名词、技术术语 | 常见同音字错误（"在坐"→"在座"） |
| **性能影响** | 几乎无影响 | 极小影响 |
| **灵活性** | 可动态指定（每个流不同） | 全局配置 |
| **是否冲突** | **不冲突，可同时使用** | **不冲突，可同时使用** |

**推荐配置**: 同时使用热词和 HomophoneReplacer，效果最佳！

```kotlin
val recognizer = modelManager.createOnlineRecognizer(
    modelType = ModelManager.ModelType.ZIPFORMER_TRANSDUCER,
    hotwordsFile = "hotwords.txt",      // 提高专有名词准确率
    hotwordsScore = 2.0F
)

// 同时，ASR 模型目录包含：
// - lexicon.txt
// - replace.fst
// 自动启用同音字纠正
```

## 热词文件最佳实践

### 1. 合理数量

- **推荐**: 10-50 个热词
- **可接受**: 50-100 个热词
- **不推荐**: 100+ 个热词（影响性能）

### 2. 词语选择

✅ **适合做热词**:
- 短词（1-5个字）: "张三"、"深度学习"
- 专有名词: "Transformer"、"BERT"
- 高频关键词: "订单"、"客户"

❌ **不适合做热词**:
- 常见词: "的"、"了"、"是"（无意义）
- 长句子: "今天天气真好"（效果差）
- 太多同义词: "买"、"购买"、"采购"（选一个即可）

### 3. 权重调优

```
1.5 - 默认值，适合大多数场景
2.0 - 中等提升，推荐值
2.5 - 较强提升
3.0 - 强提升（小心误识别）
```

**调优建议**:
1. 先用 1.5 测试
2. 如果识别率不够，逐步增加到 2.0、2.5
3. 如果出现误识别，降低到 1.5 或 2.0

### 4. 文件格式

**正确格式** ✅:
```
张三
李四
深度学习
神经网络
```

**错误格式** ❌:
```
张三,李四,王五           # ❌ 不要用逗号
张三 李四 王五           # ❌ 不要在一行
张三/3.0                 # ❌ 全局文件不支持权重
"张三"                   # ❌ 不要加引号
```

## 常见问题

### Q1: 热词不生效？

**检查清单**:
1. ✅ 热词文件是否存在？
   ```bash
   adb shell ls /data/data/你的包名/files/models/asr/hotwords.txt
   ```
2. ✅ 日志中是否有 "Hotwords enabled" 信息？
3. ✅ hotwordsScore 是否设置？（默认 1.5 效果可能不明显）

### Q2: 热词效果不明显？

**解决方案**:
1. 提高 hotwordsScore（尝试 2.0、2.5、3.0）
2. 检查热词拼写是否正确
3. 确认热词是否在模型的词表中

### Q3: 热词导致误识别？

**解决方案**:
1. 降低 hotwordsScore（尝试 1.5、1.0）
2. 减少热词数量
3. 移除与常见词相似的热词

### Q4: 可以同时使用全局热词和动态热词吗？

**答**: 可以！但是动态热词会覆盖全局热词。

```kotlin
// 全局热词
val recognizer = modelManager.createOnlineRecognizer(
    hotwordsFile = "hotwords.txt",
    hotwordsScore = 2.0F
)

// 动态热词（会覆盖全局热词）
val stream = recognizer?.createStream(hotwords = "张三/3.0 李四/3.0")
```

### Q5: 热词文件更新后需要重启应用吗？

**答**: 需要重新加载识别器。

```kotlin
// 释放旧识别器
recognizer?.release()

// 重新创建识别器（会重新加载热词文件）
recognizer = modelManager.createOnlineRecognizer(
    hotwordsFile = "hotwords.txt",
    hotwordsScore = 2.0F
)
```

## 性能影响

- **启用热词**: 几乎无性能影响（< 1% CPU）
- **热词数量**: 10-50 个热词无明显影响，100+ 可能轻微影响
- **内存占用**: 每个热词约 1KB，50 个热词约 50KB

## 总结

### 何时使用热词？

- ✅ 需要识别专有名词、人名、地名
- ✅ 需要识别技术术语、行业词汇
- ✅ 需要提高特定关键词的准确率
- ✅ 需要为不同场景使用不同热词

### 推荐配置

```kotlin
// 1. 创建热词文件（10-50 个关键词）
val hotwordsFile = File(modelManager.getModelDir(), "asr/hotwords.txt")
hotwordsFile.writeText("""
    关键词1
    关键词2
    关键词3
""".trimIndent())

// 2. 创建识别器并启用热词
val recognizer = modelManager.createOnlineRecognizer(
    modelType = ModelManager.ModelType.ZIPFORMER_TRANSDUCER,
    hotwordsFile = "hotwords.txt",
    hotwordsScore = 2.0F  // 推荐值
)

// 3. 正常使用

```

### 最佳实践

1. **热词数量**: 保持在 10-50 个
2. **权重设置**: 从 2.0 开始，逐步调优
3. **定期更新**: 根据识别效果调整热词列表
4. **组合使用**: 同时启用热词 + HomophoneReplacer
