# 快速开始指南

## 🎯 项目特点

这是一个**完全独立**的Android实时语音识别项目，具有以下特点：

✅ **Target SDK 34** (Android 14)
✅ **Java 17** 编译
✅ **PCM格式音频** - 支持接收和缓存PCM格式录音
✅ **内部存储模型** - 模型存放在 `/data/data/com.example.streamingasr/files/models/`
✅ **实时流式识别** - 边说边识别，实时显示结果
✅ **语音缓存** - 自动保存PCM录音，可导出WAV格式

---

## 📦 第一步：准备JNI库文件

### 方法A：自动下载（推荐）

```bash
cd StreamingASRApp
./download-libs.sh
```

### 方法B：手动下载

1. 访问 https://github.com/k2-fsa/sherpa-onnx/releases
2. 下载最新的 `sherpa-onnx-{version}.aar` 文件（例如 `sherpa-onnx-1.12.18.aar`）
3. 解压AAR文件（它实际上是一个ZIP文件）：
   ```bash
   unzip sherpa-onnx-1.12.18.aar
   ```
4. 复制库文件：
   ```bash
   cp -r jni/* StreamingASRApp/app/src/main/jniLibs/
   ```

完成后，你的目录结构应该是：
```
StreamingASRApp/app/src/main/jniLibs/
├── arm64-v8a/
│   ├── libsherpa-onnx-jni.so
│   └── libsherpa-onnx-core.so
├── armeabi-v7a/
├── x86/
└── x86_64/
```

## 🤖 第二步：下载语音识别模型

### 推荐：中英文双语模型

```bash
# 下载模型
wget https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-streaming-zipformer-bilingual-zh-en-2023-02-20.tar.bz2

# 解压
tar xvf sherpa-onnx-streaming-zipformer-bilingual-zh-en-2023-02-20.tar.bz2

# 进入模型目录
cd sherpa-onnx-streaming-zipformer-bilingual-zh-en-2023-02-20/
```

你需要以下4个文件：
- ✅ `encoder-epoch-99-avg-1.onnx` (约48MB)
- ✅ `decoder-epoch-99-avg-1.onnx` (约11MB)
- ✅ `joiner-epoch-99-avg-1.onnx` (约11MB)
- ✅ `tokens.txt` (约350KB)

### 其他可选模型

**纯中文模型（较小）**:
```bash
wget https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-streaming-zipformer-zh-14M-2023-02-23.tar.bz2
```

**纯英文模型**:
```bash
wget https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-streaming-zipformer-en-2023-02-21.tar.bz2
```

更多模型: https://github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models

## 📱 第三步：编译并安装应用

## 🚀 第四步：推送模型到设备

模型需要放在应用的内部存储目录：`/data/data/com.example.streamingasr/files/models/`

### 方法A：使用 run-as（无需root）

```bash
# 1. 先推送到临时目录
adb push encoder-epoch-99-avg-1.onnx /sdcard/
adb push decoder-epoch-99-avg-1.onnx /sdcard/
adb push joiner-epoch-99-avg-1.onnx /sdcard/
adb push tokens.txt /sdcard/

# 2. 使用run-as移动到应用目录
adb shell
run-as com.example.streamingasr
mkdir -p /data/data/com.example.streamingasr/files/models/
cp /sdcard/encoder-epoch-99-avg-1.onnx /data/data/com.example.streamingasr/files/models/
cp /sdcard/decoder-epoch-99-avg-1.onnx /data/data/com.example.streamingasr/files/models/
cp /sdcard/joiner-epoch-99-avg-1.onnx /data/data/com.example.streamingasr/files/models/
cp /sdcard/tokens.txt /data/data/com.example.streamingasr/files/models/
exit
exit

# 3. 清理临时文件
adb shell rm /sdcard/encoder-epoch-99-avg-1.onnx
adb shell rm /sdcard/decoder-epoch-99-avg-1.onnx
adb shell rm /sdcard/joiner-epoch-99-avg-1.onnx
adb shell rm /sdcard/tokens.txt
```

### 方法B：使用 root 权限（如果设备已root）

```bash
adb push encoder-epoch-99-avg-1.onnx /data/local/tmp/
adb push decoder-epoch-99-avg-1.onnx /data/local/tmp/
adb push joiner-epoch-99-avg-1.onnx /data/local/tmp/
adb push tokens.txt /data/local/tmp/

adb shell
su
mkdir -p /data/data/com.example.streamingasr/files/models/
cp /data/local/tmp/*.onnx /data/data/com.example.streamingasr/files/models/
cp /data/local/tmp/tokens.txt /data/data/com.example.streamingasr/files/models/
chown -R u0_aXXX:u0_aXXX /data/data/com.example.streamingasr/files/models/  # XXX是应用的UID
exit
```

### 验证模型文件

```bash
adb shell run-as com.example.streamingasr ls -lh files/models/
```

应该看到：
```
-rw-rw---- 1 u0_aXXX u0_aXXX  48M encoder-epoch-99-avg-1.onnx
-rw-rw---- 1 u0_aXXX u0_aXXX  11M decoder-epoch-99-avg-1.onnx
-rw-rw---- 1 u0_aXXX u0_aXXX  11M joiner-epoch-99-avg-1.onnx
-rw-rw---- 1 u0_aXXX u0_aXXX 350K tokens.txt
```

## 🎤 第五步：使用应用

1. 打开应用
2. **授予录音权限**（必须！）
3. 等待"模型加载成功"提示
4. 点击 **"开始识别"** 按钮（按钮会变红）
5. 对着手机说话（中文或英文）
6. 实时查看识别结果
7. 点击 **"停止识别"** 结束
8. 点击 **"导出WAV"** 保存录音（可选）
9. 点击 **"清除"** 清空结果（可选）

## 📂 文件位置说明

### 模型文件
```
/data/data/com.example.streamingasr/files/models/
├── encoder-epoch-99-avg-1.onnx
├── decoder-epoch-99-avg-1.onnx
├── joiner-epoch-99-avg-1.onnx
└── tokens.txt
```

### PCM录音缓存
```
/data/data/com.example.streamingasr/files/audio_cache/
├── audio_1234567890.pcm   # 原始PCM格式
└── audio_1234567890.wav   # 导出的WAV格式
```

### 导出文件

如需导出录音到电脑：
```bash
# 导出PCM文件
adb shell run-as com.example.streamingasr cat files/audio_cache/audio_1234567890.pcm > output.pcm

# 导出WAV文件
adb shell run-as com.example.streamingasr cat files/audio_cache/audio_1234567890.wav > output.wav

# 或者使用adb pull（需要先复制到/sdcard）
adb shell run-as com.example.streamingasr cp files/audio_cache/audio_1234567890.wav /sdcard/
adb pull /sdcard/audio_1234567890.wav
```

## 🔧 常见问题

### ❌ 问题1: "模型加载失败"

**原因**: 模型文件未正确复制到应用目录

**解决**:
```bash
# 检查文件是否存在
adb shell run-as com.example.streamingasr ls files/models/

# 如果为空，重新执行"第四步"
```

### ❌ 问题2: "UnsatisfiedLinkError: libsherpa-onnx-jni.so"

**原因**: JNI库文件未安装

**解决**:
```bash
# 检查库文件
ls -la StreamingASRApp/app/src/main/jniLibs/arm64-v8a/

# 如果为空，重新执行"第一步"下载库文件
./download-libs.sh
```

### ❌ 问题3: "识别结果为空"

**可能原因**:
- 麦克风权限未授予 → 在应用设置中手动授予
- 说话声音太小 → 靠近麦克风
- 使用错误的语言 → 中文模型只能识别中文
- 环境噪音过大 → 在安静环境测试

### ❌ 问题4: "应用闪退"

**解决**:
```bash
# 查看日志
adb logcat | grep -E "StreamingASR|sherpa"

# 常见原因：
# 1. 模型文件损坏 → 重新下载
# 2. 内存不足 → 关闭其他应用
# 3. 库文件不匹配 → 确保库和代码版本一致
```
